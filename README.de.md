# B2-Vokabel-Trainer

Eine frühe, browserbasierte Vokabeltrainer-App für das Lehrbuch **„Sicher! B2"**.

🇬🇧 English version: [README.md](README.md)

## Status: abgelöst

Dies ist die früheste Version innerhalb einer Reihe von B2-Vokabeltrainern, die auf derselben „Sicher! B2"-Wortliste basieren. Spätere Versionen erweiterten den Quiz-Funktionsumfang und bekamen schließlich Audio-Wiedergabe. **[HEY-Bist-Du-Sicher-B2](https://github.com/Kutlu24/HEY-Bist-Du-Sicher-B2) ist die aktuelle, vollständigste Version** — dort sollte für neue Arbeiten oder Deployments angesetzt werden.

## Was die App macht

Karteikarten- und Quiz-App aus reinem HTML/CSS/Vanilla-JavaScript über den Wortschatz in `sicher.csv`. Läuft komplett im Browser, kein Server, kein Build-Prozess. Wird hier nur als Referenz aufbewahrt, nicht mehr aktiv weiterentwickelt.
