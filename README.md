# B2-Vokabel-Trainer

An early browser-based vocabulary trainer for the **"Sicher! B2"** German course book.

🇩🇪 German version: [README.de.md](README.de.md)

## Status: superseded

This is the earliest version in a lineage of B2 vocabulary trainers built from the same "Sicher! B2" word list. Later iterations added a larger quiz feature set and, eventually, audio playback. **[HEY-Bist-Du-Sicher-B2](https://github.com/Kutlu24/HEY-Bist-Du-Sicher-B2) is the current, most complete version** — start there for new work or deployments.

## What it does

Plain HTML/CSS/vanilla JavaScript flashcard and quiz app over the vocabulary in `sicher.csv`. Runs entirely in the browser, no server or build step. Kept here for reference; not actively developed.
